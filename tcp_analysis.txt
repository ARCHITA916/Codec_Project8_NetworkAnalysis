# Project 8: Network Traffic Analysis

## 1. Introduction

This project focuses on capturing and analysing network traffic using Wireshark and Python. The objective is to understand how different network protocols communicate and how packet details can be examined.

## 2. Tools Used

- Kali Linux
- Wireshark
- Python 3
- Scapy library

## 3. ICMP Packet Analysis

ICMP packets were generated using the ping command.

**Observation:** ICMP Echo Request and Echo Reply packets were observed in Wireshark.

## 4. DNS Packet Analysis

DNS traffic was generated using the `nslookup` command.

**Observation:** DNS query and response packets were captured. The destination port 53 was observed.

## 5. TCP Packet Analysis

TCP traffic was generated by accessing an HTTPS website.

**Observation:** TCP communication included SYN, SYN-ACK and ACK flags. TCP packet details and stream information were examined.

## 6. UDP Packet Analysis

UDP traffic was generated using a UDP traceroute test.

**Observation:** UDP packets were identified, including DNS traffic using port 53 and traceroute probes using destination port 33434.

## 7. Python-Based Network Analysis

A Python program using Scapy was developed to read the saved TCP and UDP packet captures.

The program:
- Loads both packet capture files.
- Combines the captured packets.
- Counts TCP, UDP and other packets.
- Calculates protocol distribution percentages.
- Displays UDP source and destination IP addresses and port numbers.

## 8. Combined Protocol Statistics

**Total packets analysed: 80**

| Protocol | Packets | Percentage |
|---|---:|---:|
| TCP | 35 | 43.75% |
| UDP | 37 | 46.25% |
| Other | 8 | 10.00% |
| **Total** | **80** | **100%** |

These statistics are calculated across the two separate packet capture files.

## 9. HTTPS and TLS Analysis

HTTPS traffic was generated using the curl command and examined in Wireshark using the TLS display filter.

**Observations:**
- TLS 1.3 traffic was observed.
- Client Hello and Server Hello messages were identified.
- Server Name Indication (SNI) showed `example.com`.
- TLS Application Data packets were observed.

The encrypted application content was not decrypted or inspected.

## 10. Conclusion

This project provided practical experience in capturing and analysing network traffic using Wireshark and Python. It demonstrated the identification of ICMP, DNS, TCP, UDP and TLS traffic.

The Python program helped automate basic packet classification and protocol statistics using Scapy.

This project covers basic network traffic analysis and does not claim advanced intrusion or malware detection.
