
NETWORK TRAFFIC ANALYSIS REPORT
================================

Project: Network Traffic Analysis Using Python and Scapy

1. PROJECT OVERVIEW
-------------------
This project captures and analyses network traffic
using Wireshark, Kali Linux, Python and Scapy.

2. TCP ANALYSIS
---------------
Total packets in TCP capture: 40
TCP packets identified: 35

Destination service port observed: 443 (HTTPS)

TCP flags observed:
S  - SYN
SA - SYN-ACK
A  - ACK
PA - PSH-ACK
FA - FIN-ACK

3. UDP ANALYSIS
---------------
Total packets in UDP capture: 40
UDP packets identified: 33

UDP traffic observed:
- DNS communication (port 53)
- Traceroute probes (destination port 33434)

4. COMBINED PROTOCOL STATISTICS
-------------------------------
Total packets across both captures: 80

TCP packets: 35 (43.75%)
UDP packets: 33 (41.25%)
Other packets: 12 (15%)

Note: These statistics combine two separate captures.

5. KEY OBSERVATIONS
-------------------
- TCP traffic demonstrated connection establishment,
  data transfer and connection termination.
- DNS queries and responses used UDP.
- Traceroute generated UDP probes.
- Some captured packets used protocols other than
  TCP and UDP.

6. TOOLS USED
-------------
- Kali Linux
- Wireshark
- Python 3
- Scapy

7. LIMITATIONS
--------------
This project performs basic packet analysis and
protocol identification.

It does not currently implement malware detection,
intrusion detection or advanced anomaly detection.

8. PRIVACY NOTE
---------------
Raw packet captures are stored locally and are not
included in the public GitHub repository.


9. HTTPS AND TLS ANALYSIS
-------------------------
HTTPS traffic was captured using Wireshark while
accessing https://example.com.

Analysis Results:
- Total packets in TLS capture: 39
- Packets displayed using TLS filter: 12
- Protocol observed: TLS 1.3
- Client Hello message: Identified
- Server Hello message: Identified
- Encrypted Application Data: Identified
- Server Name Indication (SNI): example.com

Key Observations:
- Client Hello initiated the TLS handshake.
- Server Hello indicated the server response.
- Application Data packets carried encrypted traffic.
- TLS provides confidentiality for application data.

Note:
The encrypted application contents were not
inspected or decrypted.
These results come from a separate TLS capture.
